PLANT MAINTENANCE NAVIGATOR (installable app)

Files: index.html, manifest.webmanifest, sw.js, icons/

QUICK USE (no install): open index.html in any browser. It works offline.

INSTALL AS AN APP (phone and computer): the folder must be served over HTTPS once.
Easiest free way:
 1. Go to https://app.netlify.com/drop and drag this whole folder onto the page.
 2. Netlify gives you a link such as https://something.netlify.app
 3. Open the link:
    - Android (Chrome): menu > Install app / Add to Home screen
    - iPhone (Safari): Share > Add to Home Screen
    - Computer (Chrome or Edge): install icon at the right of the address bar
 After the first visit the app works without internet.
(GitHub Pages or any HTTPS web host also works.)
